# 移動可能プレビュー
制作者:ハイさん

## 概要
拡大縮小移動が可能なプレビューウィンドウを追加するツールプラグインです

## 使い方
### 【ツールの表示】
ツール→ムービングプレビュー
### 【右クリックメニュー】
#### 位置をリセット
* 拡大率や表示位置を初期位置に戻します
#### 固定
* 現在の拡大率と表示位置に固定します
